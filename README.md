## Important methodology

This site deliberately separates:

1. What a Biblical text says.
2. What archaeology independently establishes.
3. What an inscription or ancient archive says.
4. What later historians report.
5. What scholars infer from those sources.

A contextual parallel is **not automatically treated as proof** of a Biblical event or person. Debated chronology is labeled as debated, and later versions will expose competing models rather than silently selecting one.
