# The Biblical World — Historical Master Timeline

Version 0.1 is the first static foundation for the long-form Biblical historical timeline project.

## Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

## Run
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## What is included
- Responsive landing page
- Chronological timeline
- Era filters
- Search
- Event detail modal
- Biblical references
- Evidence-layer tags
- Confidence labels
- Starter source shelf with external links
- Data-driven timeline in `data/timeline.ts`
