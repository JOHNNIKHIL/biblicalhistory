# Biblical History V28–V30

This release is additive to V25–V27.

## Build fix
The V25–V27 deployment log showed nine story-index imports whose requested export names did not match the exports in their modules. The index now aliases those existing exports correctly:
- LachishCity -> Lachish
- JerichoSite -> Jerichocity
- CaesareaMaritima -> Caesarea
- MasadaSite -> Masadasite
- BabylonSite -> Babylonsite
- NinevehSite -> Ninevehsite
- UrSite -> Ursite
- EgyptAndTheNile -> Egyptnile
- SinaiWilderness -> Sinaiwilderness

## V28–V30 people layer
The project already contained many major people stories from earlier releases. This update avoids duplicating them and adds missing dedicated entries for Adam, Sarah, Aaron, Joshua and Haggai. David was already present and is retained.

Three navigational chapters are added:
- Patriarchs and Early Biblical Figures
- Exodus, Settlement and the Judges
- Kings and Prophets

No previous stories are removed.
