# V52–V54 — Explorer Foundation

Built on the complete V49–V51 redesign without removing existing content.

## Added
- Dedicated universal `/search` route with broad encyclopedia search.
- Search results spanning story title, summary, subtitle, category, chapter and location metadata.
- Bible book matches surfaced alongside encyclopedia search results.
- Dedicated `/bible` Bible Explorer.
- Structured Bible book registry for the currently available 20 book guides.
- Testament and section navigation.
- Chapter grids for every currently represented Bible book.
- Key themes/highlights per represented book.
- Direct links from Bible Explorer to the existing long-form book guides.
- Homepage search now submits to the dedicated search experience.
- Header search icon now opens `/search`.

## Preservation
All existing story data, legacy preservation files, archaeology, geography, chronology, people, historical events, book guides, timeline files and the V49–V51 redesign are retained.

## Intent
This release establishes the information architecture for the next layers: individual chapter nodes, people cross-links, places, archaeology relationships, external Bible references and eventually a connected knowledge graph.
