# V55–V57 — Bible Chapter Layer

Built on V52–V54 without deleting or replacing the existing encyclopedia data.

## Added
- `/bible/[book]/[chapter]` chapter-level pages for every currently catalogued Bible book and chapter.
- Static generation for all chapter routes in the current 20-book Bible library.
- Chapter navigation: previous, next, and all chapters.
- External full-text Bible link for each chapter.
- Chapter-level historical lens and theme structure.
- Curated chapter metadata for major Genesis, Exodus, Joshua, monarchy, exile, prophetic, Gospel and Acts passages.
- Connections from selected chapters to existing encyclopedia stories.
- Bible Explorer chapter grid now links directly to chapter pages.

## Deliberate design choice
The application does not reproduce a copyrighted Bible translation. Chapter pages provide the study layer and link outward to a Bible text provider.

## Preservation
All existing stories, people, places, archaeology, chronology, Bible guides, legacy data and redesign files remain in the release.
