# Biblical History V61–V63 — Places & Ancient World Atlas

Built additively on V58–V60. Existing stories, people, Bible explorer and chapter routes are preserved.

## V61 — Structured Places Database
- Added `content/places/index.ts`.
- Added a structured atlas dataset covering major Biblical-world cities, archaeological sites, regions and historical corridors.
- Each place includes coordinates, Biblical significance, historical significance, archaeology/evidence, Bible references, connected people, related encyclopedia stories and themes.

## V62 — Atlas Explorer
- Rebuilt `/places` around the structured place dataset.
- Added a lightweight schematic SVG atlas with clickable place chips.
- Added search and region filtering.
- Added place cards with type, region and themes.

## V63 — Individual Place Profiles
- Added `/places/[slug]` dynamic pages.
- Added quick facts, coordinates, Bible references, evidence sections, connected people and related encyclopedia entries.
- Place pages intentionally distinguish Biblical significance from independent historical/archaeological evidence.

## Notes
- The atlas map is schematic and not a geographic survey map.
- Coordinates are used for orientation and visualization, not as archaeological boundary claims.
- No external map API or API key is required.
- The existing V58–V60 content is the base; this release does not intentionally replace prior content.
