# Biblical History V70–V72 — Events, Wars, Conquests & Turning Points

## V70 — Historical Events database
Added `content/events/index.ts` with 28 structured events spanning conquest traditions, Iron Age warfare, Assyrian and Babylonian campaigns, Hellenistic conflicts, Hasmonean history and the Roman period.

Each event records type, date, era, location, summary, historical significance, Biblical context, participants, places, kingdoms, Biblical references, evidence, related encyclopedia articles, outcome, confidence and themes.

## V71 — Events Explorer
Added `/events` with search and event-type filtering.

## V72 — Individual event profiles
Added `/events/[slug]` pages connecting each event to People, Places, Kingdoms, evidence, Biblical references and related encyclopedia articles.

## Navigation
Added Events to the desktop navigation.

## Research framing
Events are explicitly labeled by confidence so well-attested historical events are distinguished from Biblical traditions with debated chronology or limited external corroboration.

## Preservation
Built additively on V67–V69. Existing Bible, people, places, kingdoms and evidence layers were preserved.
