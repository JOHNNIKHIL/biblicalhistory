# V76–V78 — Canon & Bible Traditions

## V76 — Complete 66-book Bible catalog
- Expanded the Bible Explorer from 20 books to all 66 books of the standard Protestant canon.
- Added all 39 Old Testament books and 27 New Testament books.
- Added correct chapter counts for every book.
- Preserved the existing chapter route architecture, so all books now generate chapter knowledge-node routes.
- Made book-guide links optional because historical guide articles currently exist for only a subset of the 66 books.

## V77 — Canon comparison
- Added `content/bible/canons.ts`.
- Added structured tradition profiles for:
  - Protestant
  - Roman Catholic
  - Eastern Orthodox
  - Ethiopian Orthodox Tewahedo
  - Syriac / Peshitta tradition
- Added book/material comparison for shared books, Catholic deuterocanonical books, broader Orthodox material, and distinctive Ethiopian works.
- Explicitly marks where Orthodox canon details vary rather than presenting one universal Orthodox list.

## V78 — Canon & Traditions Explorer
- Added `/canon`.
- Displays tradition-level book counts and notes.
- Lists all 66 core books.
- Provides a comparison table for major canonical differences.
- Added Canon to the main navigation.
- Updated Bible Explorer and chapter pages to point users toward canon context when a dedicated historical book guide is not yet available.

## Research principles
- Canon, manuscript tradition, translation tradition and book order are treated as distinct concepts.
- The 66-book Protestant canon is the core navigation set, not a claim that it is the universal Christian canon.
- Catholic, Orthodox, Ethiopian and Syriac traditions are represented explicitly and with variation notes where appropriate.
