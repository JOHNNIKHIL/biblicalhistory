# V82–V84 — Major Interface & Navigation Redesign

## Why this release exists
The encyclopedia grew from a simple Biblical-history timeline into a large knowledge system. The old header exposed too many destinations at once, making the application feel like a maze. V82–V84 restores a clear core journey while preserving the deeper layers.

## V82 — Navigation architecture
- Reduced desktop primary navigation to Explore, Timeline, Bible and Atlas.
- Moved People, Kingdoms, Evidence, Events, Connections, Canon, Extended Scripture and Bible Books into a single More menu.
- Added a dedicated mobile bottom navigation: Explore, Timeline, Bible, Atlas, More.
- Preserved search and theme controls.

## V83 — New home experience
- Rebuilt the hero around one clear promise: Biblical history inside its world.
- Added four explicit starting pathways.
- Removed the old feature-heavy architecture card.
- Added a readable Major Moments timeline directly to the home page.
- Retained universal search and library statistics lower on the page.

## V84 — Timeline restoration
- Replaced the old chapter-list timeline with a curated major-event chronology.
- Uses the structured historical-event dataset already present in the project.
- Each event links into its full event profile and knowledge graph.
- Designed for readable scanning on desktop and mobile.
- The complete Events database remains available separately, so the core timeline is not overloaded.

## Design principle
The application now has a simple mental model:

**Start → Timeline / Bible / Atlas → branch into deeper reference layers.**

The colors and overall editorial character are intentionally preserved; the change is primarily hierarchy, navigation, spacing and information architecture.
