# V85 — Landing Page Redesign

This release redesigns only the landing/home experience while preserving the established Biblical History visual identity.

## Goals
- Keep the existing color system and Georgia/editorial + sans-serif UI typography.
- Make the home page feel like an entry point into a historical journey rather than a dashboard.
- Reduce visual density and card overload.
- Put the timeline back near the center of the experience.
- Give users three obvious starting doors: timeline, Bible, atlas, with people as a fourth route.
- Keep search available without making it the first thing users have to understand.
- Improve mobile stacking and tap targets.

## Main changes
- Reworked hero into a large editorial title plus a compact "Choose a doorway" panel.
- Reworked StartHere into four simple, numbered paths.
- Reworked MajorTimeline into a cleaner chronological spine with fewer visual distractions.
- Reworked search section into an editorial two-column block.
- Added a short "How to use it" section explaining the product philosophy without exposing implementation architecture.
- Preserved existing data and routes.

This is a landing-page UX pass; it does not remove the underlying People, Places, Kingdoms, Evidence, Events, Connections, Canon, or Extended Scripture features.
