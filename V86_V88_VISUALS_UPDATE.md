# V86–V88 — Maps & Images Visual Layer

## V86 — Real historical maps
- Added a visual library with external historical maps from Wikimedia Commons.
- Added Ancient Near East c. 3000 BCE, Neo-Assyrian Empire, and Roman Judaea maps.
- Atlas page now includes a historical map collection in addition to the existing interactive schematic atlas.

## V87 — Primary evidence photography
- Added photographs of the Mesha Stele, Tel Dan Stele, Sennacherib's Annals Prism, and Pilate Stone.
- Evidence detail pages display a relevant image where a mapped media record exists.
- Source and license information is shown directly beneath each image.

## V88 — Visual-first landing experience
- Landing hero now uses a real historical map rather than a purely abstract panel.
- Added Visual Library route `/visuals`.
- Added Maps & Images to desktop More menu and mobile More panel.
- Added a curated maps/evidence strip to the landing page.
- Existing colors, fonts, navigation model and historical content remain intact.

## Media policy
Images are linked from Wikimedia Commons rather than silently copied into the repository. Each visual keeps its source and license attribution visible. The project can later replace selected remote media with locally hosted files where licensing and distribution rights are appropriate.
