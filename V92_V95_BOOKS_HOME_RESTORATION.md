# V92–95 — Books Library Restoration + Home Simplification

## What changed
- Restored the `/books` page to consume the complete 66-book `bibleBooks` catalog instead of filtering the older story collection.
- Added the existing tradition-specific Scripture library to the same Books experience.
- Added unified `/books/[slug]` routes for both the 66-book core and extended/tradition-specific works.
- Deep guides are surfaced when available; all other books still expose their full chapter library and existing encyclopedia guide where one exists.
- Preserved `/bible/[book]` and `/bible/[book]/[chapter]` routes.
- Simplified the homepage substantially.
- Removed the homepage map/image gallery entirely.
- Removed the redundant “How to use it” block and oversized homepage statistics/footer clutter.
- Added a single, prominent search field to the hero.
- Reduced the homepage to: hero/search → four entry points → major timeline → compact library-growth section.
- Kept the existing colors, fonts, editorial typography and visual language.

## Important preservation rule
No existing People, Places, Kingdoms, Events, Evidence, Connections, Visuals, Timeline, Canon or Extended Scripture data is intentionally removed by this update.
